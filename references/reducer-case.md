# 脱敏案例　同轴式二级直齿减速器

这份案例保存了原项目的技术输入、试选结果和用户确认后的修订路径，用于重现图样表达及测试提示词。数值为课程设计数据，适用范围为本案例。坐标单位为 mm，力为 N，转矩表为 N·m，转速为 r/min。

## 已确认任务

- 输送带单向运行，轻振动，环境温度不高于 35 °C。目标转速 37 r/min，允许误差 ±5%。减速箱输出功率 4 公制马力，按 2.941995 kW 计算。设计寿命 10 年，每年 300 天，每天 16 h，合计 48,000 h。
- 原题采用斜齿，后经用户确认切换为二级直齿并重算。保留两级等中心距及中心距末位为 0 或 5 的课程条件，两对齿数分别互质。
- 功率流为电机 → V 带 → 高速轴 I 与 z1 → 中间轴 II 上的 z2 与 z3 → 输出轴 III 上的 z4 → 联轴器 → 滚筒。轴 I 和 III 同轴、分体。轴 II 平行且偏置 190。小齿轮 z1、z3 与对应轴制成一体。
- 成果包括 11 张 DWG、计算说明书、三维零件、含箱体总装和无箱体轴系装配。11 张图分为运动简图 1 张、总装 1 张、大齿轮工作图 2 张、轴工作图 3 张、三轴结构合图 1 张及三轴受力图 3 张。运动简图在报告中也出现。
- 用户选用中文教材式视图和第一角投影。总装修订出 A0，按案例已采用的比例排图。零件和装配图采用正式视图，按用户要求只保留基本尺寸与必要参数。3D 外观统一纯白。力学图采用共用截面线、竖向填线，并给出两个平面弯矩、合成弯矩、扭矩和当量弯矩。

## 传动与齿轮台账

- 案例试选 Y112M-4，额定 4 kW、1440 r/min。V 带采用 3 根 A 型带，带轮基准直径 125 / 355，基准带长 1800，计算中心距约 510.04，带传动比 2.84，计算滑动率 1%。
- 齿轮采用 20° 渐开线直齿，螺旋角和变位系数均为零，齿顶高系数 1，顶隙系数 0.25。传动比为 149/41 和 119/33，两级总比约 13.10495。

- 箱体主体轴向范围 x = 0…380，y = −178…368，箱底 z = −200，箱盖主体最高 z = 178。分箱面为 z = 0，名义中心高 200。箱体壁厚 10，底板厚 18，分箱凸缘厚 16。模型端到端总长 572，底脚最大外宽 662，含通气附件最大高度 410。

- 端盖紧固件为 M8×30，4 组各 4 件。每组沿端盖节圆均布，起始角 45°。输入端 x = −12，两组轴心 y = 0、190，节圆直径为 100、120。输出端 x = 392，两组轴心 y = 0、190，节圆直径为 130、120。画中心线时按投影可见性处理。
- 分箱紧固件为 M12×50，共 12 件，x = 35、95、155、225、285、345 与 y = −190、380 组合。放油件 M16，油标与放油口独立表达。润滑、端盖及密封配置依据本案例的装配数据。

## 对话决策与修订证据

下表按实际沟通顺序重述已经采纳的要求，可用于评估工具有没有记住上游决定。

| 阶段 | 用户确认或反馈 | 修订动作与验收 |
| --- | --- | --- |
| 方案定版 | 保留同轴二级结构，正式改为直齿。报告、CAD 和三维模型都要一致 | 按直齿重算两级，更新统一台账及下游成果 |
| 区分图样用途 | 只有运动简图使用简图形式。装配和零件采用正式图样 | 恢复完整端视、剖视、尺寸与齿轮参数。教材和截图用来核对画法 |
| 标注取舍 | 课程图只保留基本尺寸，去掉 Ra、同轴度、配合、公差框等高级标注 | 按用户确认的标注范围核对全图。这是案例约束 |
| 轴、外观和受力图 | 三维纯白，受力图对照教材。轴的 A—A 断面和标注要留间距 | 检查装配颜色和文档分图，移动靠近断面轮廓的尺寸 |
| 键槽 | 纠正总装键槽方头，圆弧处增加十字点画线 | 核对四个圆头槽，十字标记对准八个圆弧圆心。图纸和模型分别核验 |
| 从模型生成装配图 | 另做一张来自 SolidWorks 总装的 DWG | 用模型正投影和剖面建立 A0，再补尺寸及明细。案例为获得箱座剖线使用过分箱面下 0.08 的软件出图处理，记录为本例近似 |
| 轴与箱体交叠 | 补齐轴段轮廓、修正六处轴承，消除图中的箱体与轴交叠 | 用三维投影替换贯穿箱壁的二维假线。按轴承边界尺寸重画套圈和滚珠，检查相交区域和外圈定位 |
| 齿部太密 | 先确认能否按规范简化。随后授权另存，保留上一版 | 核对齿轮表示法后处理两级密集齿线。保留可见齿顶、齿根、分度线及必要的啮合虚线，校验原文件 |
| 定版与中心线 | 选用齿部简化版，再补轴承和螺钉中心线 | 逐个核对六处轴承滚珠排中点，端视使用螺钉头十字标记，剖视中沿可见头部及杆部绘制细点画轴线 |

模型核验曾加载含箱体 79 个实例、35 种零件及无箱体 23 个实例。一次原生检查仅报告 16 处 M8 简化螺杆与螺纹底孔重叠。复用流程时以实测分类说明这类报告，仍需单独核查真实螺纹装配、底孔深度和顶死风险。二维改线与 3D 实体干涉的验证各有独立记录。

## 可复用的测试输入

| 给模型的请求 | 合格行为 |
| --- | --- |
| “先告诉我齿轮这样简化是否规范。” | 引用适用条款并限定到当前视图，先给判断。等待用户授权修订 |
